# @retainer/shared

Public types and pure helpers shared by the
[Retainer](https://github.com/Tamloot-cc/Retainer) server, SDK and web app:
field types and their composite value shapes, value validation, schema
definitions, actors, and the REST API's request and response types.

Most users want [`@retainer/sdk`](https://www.npmjs.com/package/@retainer/sdk),
which re-uses these types.
